# S010 Success Criteria

| ID | Criterion |
|----|-----------|
| S010-SC-001 | Opening the dashboard URL in a browser shows a page with live bridge state matching `outcall bridge status` output. |
| S010-SC-002 | A pending rule request can be approved via the dashboard UI, and the agent subsequently has its traffic allowed. |
| S010-SC-003 | Browser verification at desktop and mobile widths shows no document-level horizontal overflow, overlapping controls, or clipped empty states; wide tables scroll internally. |
